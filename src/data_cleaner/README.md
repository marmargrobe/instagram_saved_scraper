### Motivation
Some of the instagram post/reels that I save don't belong to a collection, or they are part of a shared collection (which I cannot scrape at the moment using the `instagrapi`). I decided to use `hugging_face` to categorize the reels based on the metadata provided, including: location, captions, hashtags, usernames, etc.
____________

### Pre-requisites
This script works with Python 3
`pip` is required to download dependencies

`.env` file is created with necessary login information
- `DB_HOST`
- `DB_PORT`
- `DB_NAME`
- `DB_USER`
- `DB_PASSWORD`
> **Note:** I'm using gcp to encrypt my .env file:
> `gpg -c .env` -> to encrypt
> `gpg -d .env.gpg > .env` -> to decrypt
____________

### How to run?

1. Make sure you have Python 3.12 installed on your machine
2. Clone the repo and then navigate inside the directory
3. Create a venv: `python -m venv .venv`
4. Install the python dependencies: `pip install -r src/data_cleaner/requirements.txt`
5. There are some tables that can be created to store your data. I am using postgres and creating my tables in sqitch:
[Sqitch Repo](https://github.com/mgrobeln/sqitch_mars)

> **Note:** This code requires that these tables exist and that the `rawstd` tables are populated using the `data_scraper` scripts. I'll can add functionality to just save this info to a csv in the repo if anyone requests.

6. Open terminal/CMD in the directory and run the script in the following manner: 
- `python -m src.data_cleaner.data_transformations`
        - This script will format the data from `rawstd` table.
- `python -m src.data_cleaner.data_categorizations --lookup_col <column values from rawstd.insta_saved_reels> --top_n <int for how many categories to return>`
        - This script will pull from the cleaned data that was generated by the previous script, it will categorize the data, and insert it into a new table with the categories.
        - `data_categorization.py` file has a set of `lookup_cols` which can be modified. The `lookup_cols` tell the `DataProcessor` which colomns to consider when categorizing the data.
        - `utils_categorization.py` file has the `DataProcessor` where the parameters can be modified. Right now, the categories are determined by the existing collections I have created in my instagram.
        

        ```
        lookup_col = 'hashtags'
        lookup_col = 'caption_text'
        lookup_col = 'city'
        lookup_col = 'location_name'
        lookup_col = ['location_name', 'city', 'lng', 'lat']
        lookup_col = ['lng', 'lat']
        lookup_col = 'usertags'
        ```




7. If everything works fine, the clean tables will be loaded.
8. Next up is to determine which categories are appropriate for each reel in the `clean.insta_saved_reels_categories` table.
